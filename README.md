# cacanny

An abstraction for a number of canbus libraries across different devices.

Currently untested, but will be soon. I have a number of devices that I want to connect via CAN:
* Feather M4 CAN (which can handle 500k but not recommended, so targetting 250k)
* Teensy 4
* Arduino R4
* the MCP 2515 breakout
* and an ESP at some point in the near future.
